# Демо интернет-магазин

Учебный проект из независимых Spring Boot микросервисов: `product-service` владеет каталогом товаров, `order-service` оформляет заказы, синхронно обращаясь к `product-service` за данными о товаре.

## Язык

**Product**:
Товар из каталога `product-service` — id, name, price. Не имеет понятия остатка/наличия (`stock`): доступен в любом количестве.
_Avoid_: Item, Item, товар (в коде — только Product)

**Order**:
Заказ на покупку количества одного Product, оформляется через `order-service`. Фиксирует цену товара (`unitPrice`) на момент создания — последующие изменения цены Product на уже созданный Order не влияют. Оформление не проверяет и не резервирует наличие товара. Неизменяем после создания: нет отмены, изменения количества или статуса (эндпоинтов для мутации нет).
_Avoid_: Purchase, транзакция
